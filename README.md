# Springshare Code Updates

This is a collection of all Look & Feel/default codes located within Springshare.  This contains the settings as of Summer 2026.  The purpose of this is have a single collection of all code for Title II accessibility updates and migrating to Bootstrap 5 by end of 2026.  When this is completed, this will serve as the main home for all Springshare related codes (general and custom).

## Current Focus

The current focus is all LibGuide codes.  LibAnswers will be soon migrating to Bootstrap 5 as well, so new directories will be created.  When there are less pressing deadlines, codes and settings will be gathered from all Springshare applications and stored here.
